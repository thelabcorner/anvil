## 2. Mechanism (exact)

Encoder discovers maximal regions `[start, start+len)` whose first differences
all lie in a 3-consecutive-integer window; boundaries and lengths are transmitted
(charged, §5). Decoder:

- the region's first word is a literal;
- `s` is either **transmitted** (control arm `param=0`) or **derived
  decoder-side from the decoded prefix with zero transmitted bits**
  (`param=1`): the first delta `d0` is coded (as data), the observed min/max
  `(lo,hi)` expand by an exact 5-symbol startup rule until `hi-lo == 2`, after
  which the residual is exactly `d - lo ∈ {0,1,2}` and the steady-state step is
  `lo+1`;
- `param=2` (`ddelta`) is a parameter-free control: second differences, alphabet
  5, no step at all.

On synth-arith this recovers exactly the generator's 8 runs: deltas per run are
exactly `{s-1,s,s+1}` for `s = 64, 83, 79, 69, 96, 48, 91, 2`; region lengths are
exactly 8,000 words; 63,992 raw deltas (63,953 steady-state ternary symbols +
31 startup symbols after the 8 first-delta literals).

### 2a. Causality statement — `s`-derivation with NO region look-ahead (binding, gate P-4)

`stride_ref.cpp` derives `s` only from bytes already reconstructed at the point
of use. Line-by-line decoder algorithm (arm B):

1. region header `(gap, len, type)` is read from the params stream (already
   available; these are transmitted structural fields, charged in §5);
2. the region's first word is a literal (literals stream);
3. the first delta `d0 = v[start+1] - v[start]` is read from the dfirst stream;
   `lo = hi = d0`; no other symbol has been consumed for this region;
4. for `k = start+2 .. start+len-1`, in order:
   - if `hi - lo == 2`: consume ONE steady-state symbol from the main stream,
     `d = lo + sym`, symbol ∈ {0,1,2};
   - else: consume ONE startup symbol; `d ∈ {lo, lo+1, lo-1, lo+2, lo-2}`
     (symbol 0..4); then `lo = min(lo,d)`, `hi = max(hi,d)`;
5. steady state: the effective step is `lo+1`, where `lo` is the minimum of the
   deltas decoded so far in this region.

Every input to every decision is a decoded delta at a position `< k`. No future
delta is consulted, no region statistics are scanned before use, no alphabet
position is transmitted. This satisfies the gate's P-4 condition as written; the
encoder mirrors the same state machine symbol-for-symbol.
