## §1 LINEAGE (measured, this host)
- t3 profile: CRC 44% of end-to-end decode (1.9 ns/B table CRC); masks/resid
  materialization 26% (setup IS masks+resid: 2.07 of 2.12 ms);
  block-concat/output-alloc/headers ~15%; token loop 11%; hot path CLEAN.
- t3 addendum: CRC cost strictly per-byte (1.86-1.91 ns/B across 4→11 blocks)
  — leg 1 generalizes to all files; projection: slice-by-8 log ~340 MB/s,
  PCLMUL-class ~406; full S6-1b legs 1+2 ~450-480 MB/s bench-scale.
- Wire-invisible fixes: slicing-by-8/16 or PCLMULQDQ CRC (IEEE values identical
  by definition); bulk/fused/lazy materialization; buffer-reuse/
  concat-elimination/alloc-reduction.
- Strategic context: macro-dvar already raw (Linux shape-delta lever does not
  transfer); stream budget alone caps ≤2-5% under bar B ⇒ S6-1's bar A not
  reachable by S6-1 alone. S6-1 STAYS FROZEN UNCHANGED; if its leg A fails,
  the t3 profile is the recorded measured explanation (implementation-era
  floor) per S6-1 §7.

## §2 WHAT IS NEW (honest: engineering only — three wire-invisible,

## §3 BINDING CONSTANTS + GUARDS
- CRC: IEEE CRC32 bit-exact; test vectors: 0xCBF43926 on "123456789" +
  full-corpus compressed-output byte-identity vs pre-S6-1b build + all 65
  format goldens re-decode hash-exact. BYTE-IDENTITY IS PRIMARY: identical
  output ⇒ identical CRC cost ⇒ decode deltas attribute purely to the leg
  under test.
- NO new production knobs; ablation flags allowed, production default = new
  paths, flag-off reproduces prior behavior exactly.
- DECOMPOSITION (binding): legs AND sub-levers (concat-elim / buffer-reuse /
  alloc-reduction) as separate staged commits or flags — a blob win cannot
  hide a sub-lever regression.
- NOISE-BAND GUARD (binding): the record's timing noise band is 5-19% and
  leg-3's expected effect (~15% residual) sits INSIDE it ⇒ plain median-3
  INSUFFICIENT for S6-1b decode claims. Decode timing verdict protocol:
  interleaved median-N with N≥7, ABBA build-order counterbalancing, warmup
  stated (in-repo precedent: t3 bench_interleaved, warmup=2, reps=7). Ratio
  rows via bench CSV unchanged-by-construction check.
- BASELINE PINNING (binding): S6-1b's per-leg decode DELTAS are measured
  against the S6-1-VERDICT build's pinned numbers (S6-1's size-neutral flips

- BOTH PLANES: alloc-pattern changes can shift encode — measure encode+decode,

- CLASSIFICATION: outcomes record as ENGINEERING-ADOPT (implementation-era) —
  never a mechanism win, never folded into EXTENDS_FRONT attribution.
