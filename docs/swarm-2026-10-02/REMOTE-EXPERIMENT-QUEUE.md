## 0. Ranking rule

A job receives remote budget only if it maximizes:

1. cross-track information gain — can one result kill/rebase several lanes?
2. frontier relevance — does it attack a measured binding deficit rather than an attractive internal metric?
3. measurement validity — same-window provenance, paired controls, correct parity, complete byte/cycle/RSS/code charges.
4. evidence admissibility — discovery/control data are not silently promoted into held-out evidence.
5. novelty honesty — if novelty is claimed, the separator must survive semantic prior-art mapping. Adopt-class engineering remains fundable when Pareto/enabling value is credible.
6. cheap falsification first — arithmetic/static/byte-only gates precede timed implementations.

A search gap is not novelty clearance. A byte-only win is not a FRONT-CROSSING.

"metadata-only" Q1 that enumerates the universe will, if implemented naively,
compute member hashes for **AITDCC I-P**, which is the project's only unopened
real family, and burn it as a side effect of an audit that was supposed to
preserve it.

**Edit E7 — Q1/Q1a MUST:**
1. operate only on retained metadata and already-open, already-consumed bytes;
2. assert **no network syscall** (enforced by counter, not by convention);
3. assert **zero codec invocations**;
4. assert **zero archive decompression** — for `archive-extract` roles, read the

   `"member_identity": "manifest-only, not decompressed"`;

**Edit E8 — `source_dirty` scope (coordinator ruling 2026-10-02).** Ruling:
